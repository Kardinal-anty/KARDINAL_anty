# KARDINAL Anty - Русская версия

##  Описание

KARDINAL Anty - это мощный антидетект-браузер, который дает вам полный контроль над вашим браузерным опытом.

## ✨ Основные возможности

- ✅ Создание неограниченного количества изолированных браузерных профилей
- ✅ Безопасное использование нескольких аккаунтов на одном устройстве через антидетект-профили (на основе [Camoufox](https://camoufox.com))
- ✅ Поддержка прокси с базовой аутентификацией для всех браузеров
- ✅ Импорт профилей из существующих браузеров
- ✅ Автоматические обновления браузеров
- ✅ Установка KARDINAL Anty как браузера по умолчанию для контроля, в каком профиле открывать ссылки
- ✅ **Полная поддержка русского языка**

## 🚀 Системные требования (Windows)

Для работы приложения на Windows необходимо:

1. **Windows 10/11** (64-bit)
2. **WebView2** (обычно уже установлен в современных версиях Windows)
3. **Для разработки дополнительно**:
   - Node.js 18+ (у вас установлена версия 24.13.0 ✅)
   - pnpm (у вас установлена версия 10.29.3 ✅)
   - Rust (у вас установлена версия 1.93.0 ✅)

## 📦 Установка и запуск

### Вариант 1: Готовая сборка (рекомендуется)
Скачайте готовый установщик для Windows (.exe) со [страницы релизов](https://github.com/CJ-aezakmi/kardinal/releases/latest)

### Вариант 2: Запуск из исходного кода (разработка)

```powershell
# 1. Клонировать репозиторий
git clone https://github.com/CJ-aezakmi/kardinal.git
cd kardinal-anty

# 2. Установить зависимости
pnpm install

# 3. Запустить в режиме разработки
pnpm tauri dev

# 4. Или собрать релизную версию
pnpm tauri build
```

## 🌍 Переключение на русский язык

**Русский язык уже полностью интегрирован!**

После первого запуска приложения:

1. Если ваша Windows на русском языке - **приложение автоматически переключится на русский**
2. Для ручного переключения:
   - Откройте настройки приложения
   - Найдите раздел "Язык" / "Language"
   - Выберите "Русский" из списка доступных языков

### Поддерживаемые языки:
- 🇷🇺 Русский (Русский)
- 🇬🇧 Английский (English)
- 🇪🇸 Испанский (Español)
- 🇵🇹 Португальский (Português)
- 🇫🇷 Французский (Français)
- 🇨🇳 Китайский (中文)
- 🇯🇵 Японский (日本語)

## 🛠️ Сборка для Windows

```powershell
# Создать инсталлятор для Windows (.exe)
pnpm tauri build
```

После сборки установочный файл будет находиться в:
`src-tauri\target\release\bundle\nsis\`

## 📁 Структура проекта

- `src/` - Исходный код фронтенда (React/Next.js)
- `src-tauri/` - Исходный код бэкенда (Rust/Tauri)
- `src/i18n/locales/` - Файлы переводов
  - `ru.json` - Русский перевод (486 строк) ✅
  - `en.json` - Английский перевод
  - и другие языки...
